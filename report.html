1. 작업 요약

출시를 앞두고 웹사이트 전체 기능을 점검하여 총 12건의 개선 및 오류 수정을 완료하였습니다. 크게 고객사 요청 기능 개선 7건과 관리자 시스템 안정화 5건으로 구성됩니다.

작업 항목 구분 내용 요약
공사실적 관리자 저장 오류 오류 수정 저장 시 DB 타입 불일치로 저장 실패하던 문제 해결
설치사례 이미지 슬라이드쇼 기능 추가 상세 모달에서 여러 이미지를 넘겨볼 수 있도록 개선
설치사례 최근 추가순 정렬 기능 개선 새로 추가한 항목이 자동으로 상단에 표시되도록 변경
비디오월 페이지 불필요 요소 제거 UI 수정 좌측 상단 브레드크럼(경로 표시) 제거
IBS / 해외프로젝트 이미지 확대 기능 기능 추가 클릭 시 이미지 전체화면 확대 및 항목 이동 기능 추가
모바일 상단 메뉴 클릭 불가 오류 수정 모바일에서 하단 메뉴 항목이 잘려 접근 불가했던 문제 해결
관리자 카드 이미지 업로드 불가 오류 수정 새 카드 추가 후 이미지 업로드 버튼이 보이지 않던 문제 해결
관리자 로그인 안정성 개선 오류 수정 반복 인증 요청으로 인한 성능 저하 구조 개선
제품 상세 관리자 페이지 오류 오류 수정 잘못된 접근 시 로딩 화면에서 멈추던 문제 해결
파트너사 저장 안정성 개선 오류 수정 저장 버튼 클릭 시 중복 처리되던 내부 로직 정리
전체 저장 결과 피드백 개선 오류 수정 저장 실패 시에도 "저장 완료"가 표시되던 문제 수정 (8개 페이지)
로그인 보안 강화 보안 외부 URL로 우회 이동이 가능하던 보안 취약점 차단

2. 기능 개선 상세

2-1. 공사실적 관리자 저장 오류 수정

현상

"사업소개 → 네트웍사업 → 공사실적" 관리자 페이지에서 내용을 수정하고 저장하면 오류가 발생하여 저장이 전혀 되지 않았습니다.

구분내용
원인 공사 용량(capacity) 항목이 데이터베이스에서 숫자형으로 설정되어 있는데, 값이 비어 있을 때 빈 텍스트("")를 전송하여 저장 오류 발생
수정 값이 비어 있을 경우 자동으로 "없음(null)" 처리하여 저장되도록 로직 수정

2-2. 설치사례 이미지 슬라이드쇼 기능 추가

현상

설치사례 항목을 클릭하면 상세 모달이 열리는데, 추가 이미지가 여러 장 있어도 첫 번째 이미지만 표시되고 다음 이미지로 넘기는 기능이 없었습니다.

구분내용
수정 • 상세 모달에 이전/다음 버튼 및 썸네일 네비게이션 추가
• 카드 목록에 추가 이미지 수량 표시 배지(+N) 추가
• 데이터 조회 시 추가 이미지 목록 포함하도록 개선

2-3. 설치사례 최근 추가순 정렬

현상

새로 등록한 설치사례 프로젝트가 목록 맨 아래에 표시되어 최신 작업 현황을 상단에서 바로 확인하기 어려웠습니다.

구분내용
기존 수동 정렬 기준으로 표시 — 새 항목은 하단에 위치
변경 최근 추가 순(내림차순)으로 정렬 — 새로 등록한 항목이 자동으로 상단에 배치

2-4. 비디오월 페이지 불필요 요소 제거

현상

비디오월(Video-Wall) 페이지 좌측 상단에 의도하지 않은 경로 표시("사업소개 / Video-Wall")가 노출되었습니다.

구분내용
수정 해당 경로 표시 영역 완전 제거

2-5. IBS / 해외프로젝트 이미지 확대 기능 추가

현상

설치사례 페이지에는 이미지 클릭 시 전체화면 확대 기능이 있었으나, IBS 및 해외프로젝트 섹션에는 동일한 기능이 없어 이미지를 크게 볼 수 없었습니다.

구분내용
수정 • 이미지 클릭 시 전체화면 모달 확대 기능 추가
• 이전/다음 항목으로 이동하는 네비게이션 버튼 구현
• 마우스 올림(hover) 시 확대 아이콘 표시

2-6. 모바일 상단 메뉴 클릭 불가 수정

현상

모바일 화면에서 상단 내비게이션 메뉴를 열었을 때, "자료실" 이후 하단 메뉴 항목들이 화면 밖으로 잘려 클릭이 불가능했습니다.

구분내용
원인 메뉴 항목 수가 많아 화면 높이를 초과하는 경우 스크롤이 작동하지 않아 하단 항목에 접근 불가
수정 모바일 메뉴 영역에 세로 스크롤 기능 적용 — 화면 내에서 모든 메뉴 항목에 접근 가능

2-7. 관리자 카드 이미지 업로드 불가 수정

현상

유지보수 관리자 페이지에서 새 카드를 추가한 뒤, 이미지가 없는 초기 상태에서 이미지 업로드 버튼이 화면에 표시되지 않아 이미지를 등록할 수 없었습니다.

구분내용
원인 이미지 업로드 버튼이 이미지가 있을 때만 보이는 구조로 되어 있어, 신규 카드에서는 버튼 자체가 투명하게 처리됨
수정 이미지 없을 때는 "업로드" 버튼을 항상 표시, 이미지 있을 때는 마우스 올림(hover) 시 "변경" 버튼 표시로 조건부 처리

3. 관리자 시스템 안정화

검증 개요
관리자 페이지 전체(18개 화면)를 정밀 점검하여 출시 전 잠재적 오류를 사전에 발굴하고 수정하였습니다.

3-1. 관리자 로그인 안정성 개선

현상

관리자 페이지 접속 시 내부적으로 인증 확인이 불필요하게 반복 실행되는 구조가 있었습니다. 이는 서버 요청을 증가시켜 응답 속도에 영향을 줄 수 있는 문제였습니다.

구분내용
원인 인증 클라이언트 객체가 화면이 업데이트될 때마다 새로 생성되어, 이를 감지한 시스템이 인증 확인을 반복 실행
수정 인증 클라이언트 객체를 최초 1회만 생성하도록 개선하여 불필요한 반복 실행 제거

3-2. 제품 상세 관리자 페이지 오류 수정

현상

관리자 제품 상세 페이지에 잘못된 경로로 접근하는 경우, 로딩 화면에서 무한히 멈추는 문제가 있었습니다.

구분내용
원인 잘못된 접근 감지 후 로딩 완료 처리가 되지 않아 화면이 계속 로딩 상태로 유지
수정 잘못된 접근 시 즉시 오류 메시지를 표시하고 로딩을 종료하도록 처리 추가

3-3. 파트너사 저장 안정성 개선

현상

파트너사 관리자 페이지에서 "전체 저장" 버튼 클릭 시 내부적으로 동일한 저장 작업이 중복 실행되는 문제가 있었습니다.

구분내용
원인 정렬 순서 저장 함수가 전체 저장 내부에 이미 포함되어 있음에도 별도로 한 번 더 호출되는 구조
수정 중복 호출 제거 및 저장 결과 검증 로직 추가

3-4. 전체 저장 결과 피드백 개선 — 8개 화면

현상

관리자 페이지에서 "전체 저장" 버튼 클릭 후 저장이 실패한 경우에도 "저장 완료!" 메시지가 표시되어, 관리자가 저장 성공 여부를 정확히 인지하기 어려웠습니다.

구분내용
수정 저장 결과를 실제로 확인하여, 성공 시에만 "저장 완료!" 메시지 표시. 실패 시 기존 오류 메시지 영역에 내용이 표시됨
적용 화면 인증서 관리, 오시는 길, 공사실적, 제품 라인업, 설치사례, 자료실, 보도자료, IBS/해외프로젝트 (총 8개 화면)

3-5. 로그인 보안 강화

현상

로그인 URL에 외부 주소를 삽입하는 방식으로 로그인 후 외부 사이트로 이동시킬 수 있는 보안 취약점이 존재했습니다.

구분내용
수정 로그인 후 이동 경로를 관리자 내부 페이지로만 제한하여 외부 URL로의 이동을 차단

4. 출시 전 확인 사항

아래 항목은 코드 수정과 별도로 수동 처리가 필요합니다.
  1. 영문 번역 데이터 적용
    IBS, 해외프로젝트, 공사실적 항목의 영문 번역 내용을 데이터베이스에 반영하는 작업이 필요합니다. (별도 제공된 SQL 파일 실행)
  2. 최종 기능 시나리오 테스트
    • 이미지 업로드 → 내용 수정 → 저장 → 새로고침 확인
    • 모바일 기기에서 전체 메뉴 접근 및 클릭 확인
    • 설치사례 / IBS / 해외프로젝트 이미지 확대 기능 확인

※ 종합 의견 : 이번 점검 작업을 통해 출시에 영향을 주는 주요 오류 및 미구현 기능이 모두 수정되었습니다. 특히 모바일 메뉴 접근 불가, 공사실적 저장 오류, 관리자 이미지 업로드 불가 등은 사용자 경험에 직접적인 영향을 미치는 항목으로 모두 해결 완료하였습니다. 영문 번역 데이터 적용 후 출시를 진행하시면 됩니다.
